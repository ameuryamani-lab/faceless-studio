# Rejected concepts — never suggest these again

Written by `add_rejected_concept` (chief_of_staff / Lester, when the owner refuses an idea, with the reason; applied at once). Meant for the agents who pick subjects (trend_scout, topic_editor, calendar_planner, strategist) through `read_brand_file "rejected.md"`. Each line should say which concept it was refused for when it is not obvious.

## Format (written by the tool)
```
- **YYYY-MM-DD** <topic or concept in a few words>
  - Reason: <the owner's reason, in their words when short>
  - By <agent> · <video id when there is one>
```

- A concept is "the same" when a viewer would say it is the same video, even with a new title.
- To bring one back, the owner must say so explicitly; mark the line `LIFTED YYYY-MM-DD`, never delete it.
